# Source manifest

Retrieval date for everything below: **2026-09-25**.

## Network conditions

This session ran in a cloud container whose egress policy denied: zenodo.org, nature.com, biorxiv.org, ncbi/pmc, evidentscientific.com (including the Adobe asset CDN hosting the IX73 manual), manualslib.com, slas.org, tpp.ch, corning.com, misumi-ec.com, thk.com, orientalmotor, hiwin, scientifica, globalspec, labwrench and the Hungarian university repositories. Only **github.com** and package registries were reachable for file download. Web *search* was available, and its result excerpts quote the publisher pages.

As a consequence, every row is marked with one of these retrieval states:

- **FILE**: the file was downloaded and inspected locally.
- **EXCERPT**: the number was read from a search-engine excerpt of the named page. The page itself could not be opened. The number is cross-checked against a second excerpt where possible (column "x-check").
- **NOT RETRIEVED**: the page is required but blocked. The user or a session with wider network access should fetch it; see `references/fetch_references.sh`.

"Authoritative" says whether the *source type* is authoritative (manufacturer or standard). "Exact/approx" describes how the value is used in the CAD.
